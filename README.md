
# Kisan Market

Kisan Market is an agriculture marketplace frontend that connects farmers and customers through a simple web interface. The project demonstrates frontend development using HTML, CSS, JavaScript and jQuery.

## About

The application provides a marketplace-style interface for agricultural products. The project is being extended with DevOps practices such as Continuous Integration, automated testing, containerization and deployment.

## Tech Stack

- Frontend: HTML5, CSS3, JavaScript, jQuery
- Backend: None currently
- Database: None currently
- DevOps: Git, GitHub, Jenkins, GitHub Actions

## Project Files

- `front1.html` — main frontend page
- `front1.css` — frontend styling
- `script1.js` — JavaScript/jQuery functionality
- `Jenkinsfile` — Jenkins CI pipeline
- `Makefile` — install, test and build commands

## Running Locally

```bash
make install
make test
make build
make run
